# Swift Student Challenge 作品总览

> 定时任务：**WWDC Swift Student Challenge 获奖作品调研 + 优化旧作 + 每日创造新作品**
> 规则：每次执行 ① 优化已有作品 ② **再造一个全新作品**（不得同质化）

## 作品清单

## 下一批候选方向（禁止重复，需与上表不同质）

1. **方言 + 听力**：助听器佩戴者与医生沟通的字幕板（端上转写 + 医学词高亮）。
2. **听力障碍者的报警器联动**：把烟感/门铃与手机、手表、灯联动（接静听与 DoseVibe 的触感资产）。
3. **村医的慢病随访清单**：把三个健康作品（乡音桥 / 记得吃 / 别怕）的数据汇成一张随访表。
4. **农村自建房安全自查**：把《合力》的地形数据变成一张贴在墙上的自查表。
5. **作品名撞名排查**：用每个作品名做一次 App Store 检索，避免投稿或上架阶段才发现冲突。

## 每个新作品的交付清单

- Package.swift 或 .playground/Contents.swift（可打开运行）
- 源码分层：模型层 / 引擎层 / 界面层 / 测试
- 单元测试（含「不误报」「不编造」「拒猜」类断言）
- README.md：问题、设计决策、代码结构、迭代记录
- Submission.md：参赛文档（三句话讲清问题、价值、边界）
- DemoScript.md：3 分钟演示脚本
