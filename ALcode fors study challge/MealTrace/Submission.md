# 一顿饭的来路 · MealTrace

## 三句话

1. **问题**：学校营养午餐只公示"菜名 + 产地"，
   家长无从知道这批菜什么时候采的、到没到安全间隔期，
   也看不出长期缺什么营养素。
2. **做法**：读公示屏上的字 → 抽取批次信息 → 倒推安全间隔期 →
   红绿两色告诉家长"能不能吃"，再指出这一餐缺什么。
3. **洞察**：一顿饭判断不了营养。
   产品的价值是**发现长期倾向**，而不是制造一顿饭的焦虑。

## 社会价值

- 让"超期采收"这件事第一次对家长可见——手里有了日期，才有资格去问。
- 让长期营养缺口（如钙、维生素 A）在体检之前被发现。
- 面向**不在孩子身边的家长**，这是农村与双职工家庭最现实的处境。

## 技术

SwiftUI · 文本解析（多字段名容错）· 安全间隔期倒推 ·
营养素计算与缺口分级 · ShareLink 家长日报。全部离线。

## 边界

营养为估算、不做执法判定、无真实 OCR 与长期趋势、演示数据未经权威校对——
这些都写在 README 里。

## 当前完成度

5 个源文件、14 个单元测试，主流程可运行，
内置一批合规批次与一批超期批次供对比演示。
