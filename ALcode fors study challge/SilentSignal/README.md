# 静听 · SilentSignal

> 把家里的声音翻译成手腕上的节奏 —— Swift Student Challenge 参赛作品

一句话：**听不见，也先知道。**

## 一、真实问题

中国有大量听障人士（老年性聋、耳鸣后遗、儿童听力障碍），
以及大量**听力正常但环境不适合开声**的时刻：
睡觉、戴着耳机、嘈杂市场、照顾哭闹的孩子。

对这些家庭来说，以下四件事会**静悄悄地错过**：

- 有人敲门（快递、邻居、物业）
- 孩子在哭
- 水开了 / 锅要糊
- 烟雾报警器响了

助听器与声光报警器能解决一部分，但价格、可携带性、夜间可靠性都不理想。
而**手机本来就有麦克风和马达**——缺的不是硬件，是"把声音翻译成触觉"的软件。

## 二、作品思路（对标获奖共性）

| 获奖共性 | 本作品的对应设计 |
|---|---|
| 从具体的人的真实痛点出发 | 睡不着的听障老人、听不到孩子哭的家长 |
| 多技术串联形成叙事 | 声学特征提取 → 规则分类 → **触觉节奏设计** → 可视化回放 |
| 端上、离线、隐私 | 声音是家里最私密的数据之一，全程不出设备 |
| 无障碍设计 | 触觉本身就是主要的输出通道；节奏用颜色 + 波形双编码 |
| 交互巧思 | **把震动节奏画出来**——设计者能调，用户能学，视频里能看懂 |

### 最关键的一个洞察

**震动传不了语义。** 一阵嗡嗡，用户根本不知道是有人敲门还是水管漏水。

所以本作品的设计原则是：**紧急度 = 强度 + 重复次数**。
摸一下手腕的力度与节拍，就能决定要不要现在爬起来。

| 事件 | 节奏 | 为什么这样设计 |
|---|---|---|
| 敲门 | 两短一长 | 与真实敲门节奏同构，不用学 |
| 婴儿哭 | 连续轻颤 | 频率高、强度低：焦急但不惊吓 |
| 水开 | 由弱到强逐渐急促 | 提醒"该过去了"，但不是警报 |
| 烟雾报警 | 长-长-长（最重） | 半夜也能把人震醒 |
| 漏水 | 急促连珠 | 像水滴落在地上的节奏 |
| 不确定 | 两短一长（轻） | 明确的"有东西，你得去看一眼" |

## 三、代码结构

      Theme.swift / ContentView.swift

## 四、诚实边界

- 界面底部常驻声明：**这不是报警器，不能替代烟感器与燃气报警器。**
- 误报代价很高（每次误报都要爬起来看），所以分类器宁可报"不确定"。
- 音乐、电视、说话声属于已知干扰，当前版本不做专门抑制——
  这是下一步，也是这个方向真正的难点所在。

## 五、下一步

1. 接入 AVAudioEngine 真实采集 + SoundAnalysis（Apple 官方声音分类模型）。
2. 学习用户习惯：常被误报的时段自动提高阈值。
3. 与 Apple Watch / HomePod 联动，把节奏送到手腕和床头灯。
4. 把"不确定"这一类做细：至少区分"有人在附近说话"和"机器噪音"。

### v2（本轮）：让用户信得过这个设备

误报是这类产品唯一的死法——错报三次，人就不看了。
所以本轮加了两道闸门：

1. **干扰识别**（InterferenceGuard.swift）：用同一套声学特征识别
   稳态的家电/车流、强起伏的音乐与人声，识别为干扰后**不触发震动**。
2. **去抖动 + 严格度**（AlertGate.swift）：非紧急事件需连续确认
   N 次（N 由用户选择的严格/均衡/宽松决定）；**烟雾与漏水绕过全部闸门**，
   一次识别就提醒。
3. 首页新增灵敏度面板，实时显示"当前像背景音乐"，并统计已拦下多少误报。
4. 测试 20 → 31 个（新增去抖动、严格度、干扰抑制、危险事件旁路、敲门不被误判为干扰）。

### v3（本轮）：补上竞品打出的那张牌

联网核验后发现：**Vigilant Ear: Deaf Sound Alert**（App Store 5.0★）
主打的是「声音来自哪个方向、多远」——这是我们没有的功能。

本轮新增 SoundLocator，但**没有照抄，而是先把物理边界写进代码**：

1. **单麦克风时拒绝给方位**。没有双通道输入时返回 bearing = nil、
   可信度低于 0.3，并附一句说明：
   "只有一个麦克风时，物理上无法判定方向。这里的距离也只是粗略分档，别当成尺子用。"
2. 有双通道输入时才做左右判定，且左右能量差小于阈值时**读作正前方**，不硬分。
3. 距离只给**四档**（很近 / 同一间屋 / 隔壁楼上 / 较远），
   不假装米级精度——可靠的距离线索是直达声与混响比，那需要麦克风阵列。
4. 测试 31 → 37 个（单通道拒绝编造、左右判定、差异过小读作正前方、可信度随差异递增）。
