# 别信 · DontFool

> 独居老人面对诈骗话术的实时提示 —— Swift Student Challenge 参赛作品

一句话：**对方说的话，帮你听出不对劲。**

## 一、真实问题

老年人是电信诈骗的主要受害者之一，而且**多数是在独自在家时被骗的**：
没有家人在旁边质疑，手机就在耳边，对方还有时间压力。

现有的反诈工具全都帮不上这类人：

1. **国家反诈中心 App**：功能强，但**年轻人装、老年人不用**，且要主动输入可疑号码。
2. **拦截电话的运营商服务**：只挡号码，骗子换号就打进来。
3. **家人的口头提醒**：平时都说过了，真到那天谁都想不起来。

真正的缺口是：**当那句关键的话在电话里被说出来时，能不能当场有一句话提醒老人。**

## 二、作品思路（对标获奖共性）

| 获奖共性 | 本作品的对应设计 |
|---|---|
| 从具体的人的真实痛点出发 | 独自在家的老人、骗子正在电话里说话的那 30 秒 |
| 多技术串联形成叙事 | 语音流 → 滚动窗口 → 套路组合判定 → 分级提醒 → 唯一正确动作 |
| 端上、离线、隐私 | 电话内容是最私密的数据，**全程不出设备** |
| 无障碍设计 | 触觉分级（一路到四路）+ 大字 + 一屏说清"现在该做什么" |
| 交互巧思 | **不拦电话，只在关键话术出现时补一句** |

### 三个设计决定

1. **认套路结构，不认关键词**
   骗子的话每天都在变（今天公检法，明天快递理赔），但结构不变：
   制造恐慌 → 要求保密 → 要求转账或屏幕共享。
   所以我们识别**组合**，单一特征只提示"再听两句"。
2. **出现转账类要求时不等组合，立刻到最高级**
   "转��安全账户""共享屏幕""说验证码"这类要求出现即红色——
   这三个词单独出现就已经足够危险。
3. **给动作，不给恐慌**
   每条建议都是一句可执行的话："挂断，自己拨打 96110 核实，不要回拨对方给的号码。"
   而不是"当心诈骗"这种正确的废话。

## 四、诚实边界

- **这不是防诈骗软件，也拦不住电话**。界面底部常驻声明：
  96110 和 110 永远是可信的。
- 话术库是**有限的**，新套路的覆盖需要持续补充——这正是把它做成社区共建词库的理由。
- 没有真实通话链路（AVAudioEngine + CallKit 观察），
  目前靠外部转写的文本输入。
- 存在误报的可能：我们选择**宁可多提示一句，也不要漏**，
  但仍要求"单个词不报警"这条线由测试守住。

## 五、下一步

1. 接端上语音转写（流式），做到真正的"边听边判"。
2. 触觉分级接入 CoreHaptics，让老人不用看屏幕也知道该不该挂。
3. **社区共建话术库**：让被骗过的老人把自己的经历加进去——
  受害者是最有价值的语料来源，这一点和乡音桥的词库共建是同一个思路。
4. 与《别怕》《静听》共用触感资产，做成"看不见也能用"的一组作品。

### v2（本轮）：被骗过的人，是最好的语料老师

官方黑名单永远追不上新套路，而**亲历者记得骗子的每一句话**。
本轮把这句话变成了产品功能：

1. **社区共建话术库**（ScamCorpus.swift + CorpusView.swift）：
   老人把骗子的原话写下来 → 自动抽取结构词 → 进入待审核区。
2. **签字要两把钥匙**：只有社区民警、反诈人员或社区工作者能签字通过；
   普通人点通过会被拒绝并给出说明——受害者的话也不能直接变成判定依据。
3. **个人信息不进词库**：只抽结构词（涉嫌、保密、转账、安全账户），
   姓名、工号、卡号一律不进——测试里专门守这条线。
4. 全部留在本机，不上传。
5. 测试 14 → 19 个（新增抽取、待审核、签字权限、个人信息不泄漏）。
