# 记得吃 · DoseVibe

## 三句话

1. **问题**：用药提醒 App 只会响铃和"点击已服用"，
   却对降糖药、抗凝药一律暗示"补服"——这在临床上可能造成严重后果。
2. **做法**：按药物类别做**漏服分级**：危险药物的界面上根本不存在补服按钮，
   只提示联系医生；确认需家属鉴权；震动区分"该吃"与"出事了"。
3. **洞察**：依从性产品的价值不在"提醒得准"，而在**出问题时不给错建议**。

## 社会价值

- 减少低血糖、出血、心律失常等**由"好心补服"造成的二次伤害**。
- 子女第一次真正知道父母今天吃药没有（而不是听到一句"吃了"）。
- 让"确认"这件事不再是老人随手一划。

## 技术

SwiftUI · CoreHaptics 三档节奏 · 规则引擎（漏服分级）·
确认鉴权抽象 · ShareLink 日报。全部离线，健康数据不出设备。

## 边界

不给用药建议；药物分类未经临床药师审校，这一点写在 README 里而不是藏起来。

## 当前完成度

7 个源文件、15 个单元测试，主流程可运行，
内置一个典型的"降压 + 降糖 + 抗凝 + 镇静"老人方案。
